# CIS25
Week 8 – Bank Account Simulation

This program uses a BankAccount class to keep track of a balance.

This code starts the account with a balance of 0

Adds money using a deposit function

Makes purchases if there is enough money

Prints the final balance

Saves each deposit and purchase to a file called transactions.txt

In main(), the program creates a bank account, adds an initial deposit, makes two purchases, and then displays the final balance.

The transaction file is updated every time the program runs.
