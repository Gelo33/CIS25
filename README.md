# CIS25

Module 4 Debugging and Logic

This folder contains two C++ programs for Module 4.

Module4Part1.cpp
This program displays a simple menu using if and else if statements. The user is asked to choose an option, and the program responds based on the selection. It was created to practice logical conditions and decision making.

Module4Part2.cpp
This program asks the user to enter three numbers and then outputs the largest number. The original code had several syntax and logic errors, which were fixed. The final version uses nested if statements as required.

these programs used input/output, logical operators, and if statements.
